# 跨境电商 OpenClash 防泄漏 / 防关联方案 · 总目录

一套面向**跨境电商 / 多账号运营**的 OpenClash 完整方案。三大目标：
1. **防泄漏** —— 杜绝 DNS / IPv6 / WebRTC 泄漏，出口 IP 与归属地不被暴露；
2. **防关联** —— 各平台独立分组、每账号可固定落地 IP；
3. **断网保护** —— OpenClash 一挂，指定设备立刻断网，绝不回落国内直连。

## 🚀 从 0 到上线：推荐顺序

### 第 1 步 · 搭后端（让订阅自带防泄漏 DNS）
自建 subconverter，把 `clash_rule_base` 指向 [Custom_Ecommerce_Base.yaml](./Custom_Ecommerce_Base.yaml)。
→ 详见 [Custom_Ecommerce.md](./Custom_Ecommerce.md) 第「4.1 自建后端 + 防泄漏 base」节。

### 第 2 步 · 转换订阅
用你的机场/专线订阅 + [Custom_Ecommerce.ini](./Custom_Ecommerce.ini) 模板，经后端生成 Clash 订阅链接。
→ URL 拼法见 [Custom_Ecommerce.md](./Custom_Ecommerce.md) 第三节。

### 第 3 步 · OpenClash 设置（防泄漏）
运行模式 = Fake-IP；自定义DNS **不勾**（用文件的）；禁 IPv6；开 **TUN + UDP转发 + 禁QUIC + DNS代理 + 域名嗅探**；更新 GEO 数据库。
→ 原理见 [README.md](./README.md)。

### 第 4 步 · 防关联（每账号固定 IP）
进各平台组，给每个账号钉一个固定落地节点，长期不变；养号网段用 `SRC-IP-CIDR` 指定出口。

### 第 5 步 · 断网保护（kill-switch）
LuCI 防火墙 → 通信规则，给养号设备加"源=设备网络 / 目标=所有出口 / 动作=丢弃"。
→ 详见 [KillSwitch-断网保护.md](./KillSwitch-断网保护.md)。

### 第 6 步 · 验证
- DNS：dnsleaktest.com（无中国 DNS）
- WebRTC：browserleaks.com/webrtc（不显真实 IP）
- IPv6：test-ipv6.com（无 IPv6）
- 出口/指纹：whoer.net / pixelscan.net（国家一致、匿名≥90%）
- 断网：停掉 OpenClash → 养号设备立刻断网

## ⚠️ 配置之外，决定成败的三件事
1. **浏览器时区/语言**改成节点所在国（时区不匹配 = 秒被识破）；
2. **浏览器关闭 WebRTC**（Clash 只能拦 STUN，浏览器层必须再关）；
3. **用住宅 IP + 指纹浏览器**（一账号一环境）。

> 详见 [README.md](./README.md) 的"最严格运营环境清单"。
